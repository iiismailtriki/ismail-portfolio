# Portfolio Audit — Modernization Pass (2026-11-09)

Scope: full codebase, live site (`https://iiismailtriki.github.io/ismail-portfolio/`, inspected in a
real browser at 1024×768 and 375×812), deployment workflow, dependencies, and a fresh re-audit of
the `devsecops-deployment-tracker` repository (HEAD `b09d42c`, 2026-10-03).

Baseline: Astro 4.16.19, Tailwind 3.4.19, `@astrojs/tailwind` 5.1.5. Build succeeded (5 pages).
No type checking, lint, or link checks existed.

## Critical

| # | Finding | Evidence |
|---|---|---|
| C1 | **Project content is out of date with the flagship repo.** The site says the Helm chart "exists only locally, not yet committed". It has been committed and merged (PR #2, `templates/` for Deployment, Service, NetworkPolicy, helpers, resource requests/limits). A recruiter who opens the repo sees the portfolio understating — and contradicting — the actual work. A CVE remediation PR (#1, pinned `libpcre2-8-0`) is also not mentioned. | `git log` of the tracker repo |
| C2 | **14 known vulnerabilities in the dependency tree, 1 critical** (`astro <=7.3.1`), 10 high (vite, esbuild, zod, sharp, postcss, …). Build-time only, so the static output is not directly exploitable — but a DevSecOps portfolio with open Dependabot-class findings undercuts its own message. Fix requires Astro 7 + Tailwind 4 (`@astrojs/tailwind` is not compatible with Astro ≥6). | `npm audit` |

## High

| # | Finding |
|---|---|
| H1 | **Google Fonts loaded from Google's servers** via CSS `@import`. In Germany this is a known GDPR issue (LG München I, 3 O 17493/20, 2022) and it is a render-blocking request chain (CSS → fonts CSS → font files). |
| H2 | **Mobile first screen shows no name or role for ~1.5 s.** The 240 px portrait sits above the headline, and every hero element starts at `opacity: 0` and waits for the scroll observer. On 375×812 the name lands at ~470 px, still fading in. |
| H3 | **All content below the hero is invisible without JavaScript** (`.animate-on-scroll` defaults to `opacity: 0`). Affects no-JS readers, some crawlers/link previewers, print, and screenshot tools. |
| H4 | **Internal note leaked to the public page.** The Vocallia card shows "…to be added — see docs/content-source-of-truth.md" to visitors. |
| H5 | **Unoptimized images.** Two architecture diagrams are 1.5 MB PNGs each; the 1081 px Nutanix badge (187 KB) is displayed at 56 px; the profile PNG is 217 KB. No `width`/`height` on most images (layout shift). |
| H6 | **Sitemap is hand-written and stale** — missing `/devsecops-case-study/`, the flagship case study. |
| H7 | **Recruiter path is slow.** Order is Hero → About → Skills → Projects, so the strongest evidence (projects) starts ~2,500 px down on desktop and ~4,100 px on mobile (page is 15,800 px tall on mobile). |
